Da interface ao banco de dados

Sou formado no curso técnico em Informática para Internet pela Etec Astor de Mattos Carvalho e curso Análise e Desenvolvimento de Sistemas na Unimar. Hoje sou estagiário de desenvolvimento na Airys, atuando com integrações da API do WhatsApp, banco de dados e servidores no AirysChat, uma plataforma de atendimento e automação com IA.
