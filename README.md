# Portfólio — Rayluan Silva

Meu portfólio pessoal, com os projetos que desenvolvi durante o curso técnico em Informática para Internet (ETEC) e depois dele.

🔗 **Acesse online:** https://rayluansilva.github.io/Portfolio_Rayluan/

## Projetos incluídos

| Projeto | Descrição | Link |
|---|---|---|
| **Site de Hábitos Saudáveis** | Projeto Integrador da ETEC. Cadastro e login, registro de hábitos, calendário, conquistas e tema claro/escuro, com os dados salvos no navegador via `localStorage`. | [abrir](https://rayluansilva.github.io/Portfolio_Rayluan/sites/habitos/inicio.html) |
| **Calculadora de Energia** | Cálculo de consumo por tipo de cliente (residencial, comercial e industrial), com fatura e simulação de pagamento com troco. | [abrir](https://rayluansilva.github.io/Portfolio_Rayluan/sites/CalculoEnergia.html) |
| **Aprova ou Reprova** | Calcula a média dos 4 bimestres e indica aprovação ou reprovação. | [abrir](https://rayluansilva.github.io/Portfolio_Rayluan/sites/AprovaouReprova.html) |
| **Saque Bancário** | Simula um caixa eletrônico e calcula a menor quantidade de cédulas para o valor. | [abrir](https://rayluansilva.github.io/Portfolio_Rayluan/sites/SaqueBancario.html) |
| **Calculadora de Combustível** | Calcula o gasto de uma viagem a partir de preço, consumo e distância. | [abrir](https://rayluansilva.github.io/Portfolio_Rayluan/sites/CalculadoraCombust%C3%ADvel.html) |

O portfólio também apresenta o **Simulando** (meu TCC, em PHP e MySQL, hospedado à parte), o **Salão da Leila** e o **Burger on the Grill**, que têm repositórios próprios.

## Tecnologias

- HTML5 semântico e CSS3 (Flexbox e layout responsivo)
- JavaScript puro (manipulação do DOM, eventos, `localStorage`)
- Bootstrap Icons e Font Awesome (ícones via CDN)

## Estrutura

```
index.html            página principal do portfólio
styles/styles.css     estilos do portfólio
script/script.js      menu, rolagem suave, janelas de detalhes dos projetos e formulário de contato
sites/                projetos acadêmicos
  habitos/            Site de Hábitos Saudáveis (inicio.html → login.html → home.html)
```

## Como rodar localmente

Não precisa instalar nada: basta abrir o `index.html` no navegador.
